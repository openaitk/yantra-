How to read these prices

AI APIs charge separately for input tokens (your prompt) and output tokens (the answer). A token is roughly ¾ of a word, so 1M tokens is about 750,000 words. Output tokens usually cost several times more than input tokens, so a chatbot that writes long answers costs more than one that writes short ones.

Estimate your own cost

Cost per request = (input tokens × input price + output tokens × output price) ÷ 1,000,000. For example, a request with 1,000 input and 500 output tokens on GPT-4o mini costs about ₹0.04. The models page has a calculator that does this for your monthly usage.

How it works

You top up a balance in rupees with UPI (minimum ₹10) and get one API key. Your code calls Yantra exactly like it calls OpenAI: the same SDK, the same request and response shape. You pay per token from your balance, with no subscription and no monthly fee.

Frequently asked questions

What is the price of the GPT API in rupees?

On Yantra, GPT-5.5 costs ₹543.95 per 1M input tokens and ₹3,260.25 per 1M output tokens. Cheaper GPT models are listed above.

Are these prices final?

Prices follow the upstream providers and can change. This page is regenerated from the live catalogue; the models page always shows current prices.

Is GST included?

Prices shown are per-token prices. Check the checkout screen for the final payable amount when you top up.

Do I need an international credit card?

No. You pay with UPI in Indian rupees. The minimum top-up is ₹10.

Is this the official provider API?

No. Yantra AI is an independent gateway. It routes your request to the model provider and bills you in rupees.
