How it works

You top up a balance in rupees with UPI (minimum ₹10) and get one API key. Your code calls Yantra exactly like it calls OpenAI: the same SDK, the same request and response shape. You pay per token from your balance, with no subscription and no monthly fee.

  • Multilingual prompts, including Indian and East Asian languages.

Example

Change the base URL and key in your existing code, then set the model id:

from openai import OpenAI

client = OpenAI(
    base_url="https://api.aitklabs.in/v1",
    api_key="yk_live_xxxxxxxxxxxx",
)

response = client.chat.completions.create(
    model="qwen/qwen3.6-27b",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
