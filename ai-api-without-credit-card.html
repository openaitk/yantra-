Use AI APIs without an international credit card

Students and indie developers in India often can’t pay AI providers because their cards don’t support international payments. Yantra AI lets you pay with UPI and use many models through one API key.

Get an API key →

Who this is for

Students, freelancers and small teams in India who want to build with AI APIs but don’t have an international credit card, or who prefer to pay in rupees and avoid foreign-currency conversion on each top-up.

How to start in a few minutes

1) Create an account. 2) Top up from ₹10 with UPI. 3) Copy your API key. 4) Point your OpenAI-compatible code at https://api.aitklabs.in/v1. You can also try models in the playground first.

Costs stay predictable

You pay per token from a prepaid balance, so there is no surprise monthly bill. Prices for every model are shown in ₹ on the models page.

from openai import OpenAI

client = OpenAI(
    base_url="https://api.aitklabs.in/v1",
    api_key="yk_live_xxxxxxxxxxxx",
)

response = client.chat.completions.create(
    model="openai/gpt-5.5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
