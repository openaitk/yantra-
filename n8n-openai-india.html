Use OpenAI, Claude and Gemini in n8n from India (with UPI)

n8n’s OpenAI nodes let you point at any OpenAI-compatible API. That means you can run GPT, Claude, Gemini or DeepSeek in your n8n workflows from India with one key and rupee billing.

Get your API key →

Steps

  1. Create a Yantra account, add credit with UPI (minimum ₹10) and create an API key on the dashboard.
  2. In n8n open Credentials → New → OpenAI API.
  3. Paste your key (it starts with yk_live_) into API Key.
  4. Set Base URL to https://api.aitklabs.in/v1 and save.
  5. Add an OpenAI Chat Model (or the OpenAI node) to your workflow and select the credential.
  6. Choose a model. If the list is empty, switch the model field to By ID and type an id such as openai/gpt-5.5, anthropic/claude-sonnet-5-5 or auto:cheap.

Calling it from an HTTP Request node

You can also use n8n’s HTTP Request node with the same endpoint:

POST https://api.aitklabs.in/v1/chat/completions
Authorization: Bearer yk_live_xxxxxxxxxxxx
Content-Type: application/json

{
  "model": "auto:cheap",
  "messages": [{"role": "user", "content": "Summarise this email: {{ $json.text }}"}]
}

Tips for workflows

  • Use auto:cheap for classification and extraction steps, and a stronger model only where quality matters.
  • Set a credit limit on the key you give n8n, so a looping workflow cannot drain your balance.
  • Servers that call the API from the cloud (AWS, Hetzner and similar) work normally.
  • Images: the same key works with /v1/images/generations from an HTTP Request node. See the image API guide.

How it works

You top up a balance in rupees with UPI (minimum ₹10) and get one API key. Your code calls Yantra exactly like it calls OpenAI: the same SDK, the same request and response shape. You pay per token from your balance, with no subscription and no monthly fee.

Frequently asked questions

What base URL do I use in n8n?

https://api.aitklabs.in/v1, in the OpenAI API credential.

Can I use Claude or Gemini in n8n this way?

Yes. Use the model id, for example anthropic/claude-sonnet-5-5 or google/gemini-3.8-flash, through the same OpenAI credential.

How do I stop a workflow overspending?

Create a key with a credit limit and a daily, weekly or monthly reset, and use that key in n8n.

Do I need an international credit card?

No. You pay with UPI in Indian rupees. The minimum top-up is ₹10.

Is this the official provider API?

No. Yantra AI is an independent gateway. It routes your request to the model provider and bills you in rupees.
