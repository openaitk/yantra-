Using GPT-4o mini from India

Yantra speaks the OpenAI API, so an existing integration needs two changes: the base URL and the key. Everything else — the SDK, the request shape, the response shape — stays exactly as it is.

from openai import OpenAI

client = OpenAI(
    base_url="https://api.aitklabs.in/v1",
    api_key="yk_live_xxxxxxxxxxxx",
)

response = client.chat.completions.create(
    model="openai/gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
