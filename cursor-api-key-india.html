Use Cursor with your own API key in India (pay with UPI)

Cursor lets you bring your own OpenAI-compatible key. Point it at Yantra and you can run Claude, GPT, Gemini and DeepSeek models from India, billed in rupees by UPI, with no international card.

Get your API key →

Set it up in Cursor

  1. Create a Yantra account and a key. It starts with yk_live_.
  2. In Cursor open Settings → Models.
  3. In the OpenAI API key section, paste your Yantra key.
  4. Turn on Override OpenAI Base URL and enter https://api.aitklabs.in/v1.
  5. Choose Add model and type a model id exactly, for example anthropic/claude-sonnet-5-5 or deepseek/deepseek-v4-flash.
  6. Press Verify, then pick the model in the chat box.

Model ids come from the models page. You can also use auto, which picks a working model for you.

What to expect

  • Chat and edit features that accept a custom OpenAI key will use your Yantra balance.
  • Features tied to Cursor's own models (such as its built-in autocomplete) are separate and are not billed to Yantra.
  • Menu names change between Cursor versions. If you cannot find a setting, search for "base URL" in Cursor's settings.

What it costs

Coding tools send a lot of text with every request (your open files and the conversation so far), so cost depends on the model you pick. As a rough guide, a typical request of about 8,000 tokens in and 800 tokens out costs around ₹0.37 on DeepSeek V4 Flash (-> V4.1) and around ₹2.61 on Claude Sonnet 5.5. That is roughly 273 requests versus 38 requests for ₹100. Your real numbers will differ, and the dashboard shows the exact cost of every call.

Keep spending under control

  • Create a separate key for this tool in the dashboard and give it a credit limit (for example ₹200 a month). If the tool loops, the key stops and the rest of your balance is safe.
  • Top up small. The minimum is ₹10 by UPI, and unused balance stays in your account.
  • Use deepseek/deepseek-v4-flash for everyday edits and a stronger model such as anthropic/claude-sonnet-5-5 only for hard problems.

Frequently asked questions

Do I need an international credit card?

No. You pay with UPI in Indian rupees. The minimum top-up is ₹10.

Is this the official provider API?

No. Yantra AI is an independent gateway. It routes your request to the model provider and bills you in rupees.

Which models work for agent and tool-calling features?

Use a model tagged for tools, such as anthropic/claude-sonnet-5-5 or deepseek/deepseek-v4-flash. The models page shows which models support tools.
