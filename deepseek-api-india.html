How it works

You top up a balance in rupees with UPI (minimum ₹10) and get one API key. Your code calls Yantra exactly like it calls OpenAI: the same SDK, the same request and response shape. You pay per token from your balance, with no subscription and no monthly fee.

Good uses for DeepSeek

  • Low-cost coding assistants and agents where token volume is high.
  • Bulk summarising, classification and extraction at a low price per request.
  • A cheap default model with automatic fallback to another model if DeepSeek is busy.

Example

Change the base URL and key in your existing code, then set the model id:

from openai import OpenAI

client = OpenAI(
    base_url="https://api.aitklabs.in/v1",
    api_key="yk_live_xxxxxxxxxxxx",
)

response = client.chat.completions.create(
    model="deepseek/deepseek-v4.1-flash",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)

DeepSeek models on Yantra start at ₹32.60 per 1M input tokens and ₹130.41 per 1M output tokens (DeepSeek V4.1 Flash). See the table on this page for every model.

No. Yantra AI is an independent gateway. It routes your request to the model provider and bills you in rupees.
