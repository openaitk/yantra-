OpenAI API in India — pay with UPI

Want to use GPT models from India but your debit card declines international payments? Yantra AI is an OpenAI-compatible API gateway that bills in Indian rupees and accepts UPI.

Get an API key →

The problem

Paying OpenAI directly usually needs an international credit card. Many Indian debit cards have international transactions disabled, and a failed payment is the most common reason developers get stuck before writing their first line of code.

How Yantra works

You top up a balance in ₹ using UPI. You get one API key. Your code calls Yantra exactly like it calls OpenAI — same SDK, same request and response shape — and you pay per token from your balance. Nothing to subscribe to, and the minimum top-up is ₹10.

What it costs

GPT-5.5 costs ₹543.95 per 1M input tokens and ₹3,260.25 per 1M output tokens. Every model has its own price, shown in ₹ on the models page.

from openai import OpenAI

client = OpenAI(
    base_url="https://api.aitklabs.in/v1",
    api_key="yk_live_xxxxxxxxxxxx",
)

response = client.chat.completions.create(
    model="openai/gpt-5.5",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)

Frequently asked questions

Do I need an international credit card?

No. You pay with UPI in Indian rupees.

What do I change in my code?

Only the base URL (https://api.aitklabs.in/v1) and the API key. The OpenAI SDK, request format and response format stay the same.

What is the minimum top-up?

₹10.

Is this official OpenAI?

No. Yantra AI is an independent gateway that routes your requests to model providers.
