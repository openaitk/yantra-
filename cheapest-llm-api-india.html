Cheap does not mean weak

Small models are great for classification, extraction, short answers and simple chat. For hard reasoning, long coding tasks or careful writing, a more capable model is usually cheaper overall because it needs fewer retries. A good pattern is to default to a cheap model and send only the difficult requests to a stronger one.

Let Yantra pick for you

Set the model to auto:cheap to route to a low-cost model, or auto:reasoning for harder work. If a provider is busy or down, the request is retried on another host automatically.

from openai import OpenAI

client = OpenAI(
    base_url="https://api.aitklabs.in/v1",
    api_key="yk_live_xxxxxxxxxxxx",
)

response = client.chat.completions.create(
    model="auto:cheap",
    messages=[{"role": "user", "content": "Hello"}],
)
print(response.choices[0].message.content)
